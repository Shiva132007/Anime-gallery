#  Anime Gallery

A modern Anime Gallery web app built using React and the Jikan API.  
Browse anime characters, explore images, and enjoy a clean dark-themed UI.

---

## Live Demo

 https://shiva132007.github.io/anime-gallery/

---

##  Features

-  Anime character gallery
-  Character images
-  Dark modern UI
-  Fast React application
-  Responsive design
-  API integration using Jikan API

---

##  Tech Stack

- React
- CSS3
- JavaScript
- Vite
- Jikan Anime API

---

##  API Used

Jikan API  
https://jikan.moe/

Example Endpoint:

```bash
https://api.jikan.moe/v4/anime/20/characters
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Shiva132007/anime-gallery.git
```

Go to project folder:

```bash
cd anime-gallery
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

##  Build Project

```bash
npm run build
```
